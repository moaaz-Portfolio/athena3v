# بروتوكول تجارب Athena 2.0 — تعرّف النشاط وأنماط السقوط المحتملة

## السؤال العلمي
هل يميز نموذج CSI تسلسلًا حركيًا مرتبطًا بالسقوط عن الأنشطة اليومية المشابهة، مع الحفاظ على الأداء عند تغيير الغرفة أو الشخص أو الجهاز؟ وهل نافذة زمنية أطول وتعلّم زمني متعدد المقاييس يحسّنان النتائج مقارنةً بالـ baseline والنموذج القديم؟

## الأنشطة والبيانات
ابدأ بالفئات الأساسية التالية:

- `empty`: لا يوجد شخص في منطقة الاستشعار.
- `sitting_still`: جلوس ثابت.
- `walking`: مشي طبيعي.
- `sitting_down`: الانتقال الطبيعي إلى الجلوس.
- `lying_down`: الاستلقاء الطبيعي.
- `fall`: فئة بحثية منفصلة، ولا تُسجّل إلا من أمثلة آمنة ومصرّح بها وتحت إشراف بالغ مؤهل وعلى سطح مبطن. لا تحاول تنفيذ سقوط حقيقي أو أي حركة خطرة.

أضف كـ hard negatives عند الحاجة: `bending`, `squatting`, `turning`, `kneeling`, `picking_up_object`, `quick_sitting`. تسجيل الحركات المشابهة مهم حتى لا يتعلم النموذج أن كل حركة مفاجئة تعني سقوطًا.

**الحد الأدنى للبرمجيات ليس هو الحد الأدنى للبحث العلمي.** الكود يقبل 3 تسجيلات لكل فئة للتشغيل التجريبي، لكن ابدأ بـ 10–20 تسجيلًا مستقلًا لكل فئة، ويفضل 20+ لفئة السقوط، موزعة على أيام واتجاهات ومسافات وأوضاع مختلفة. كل مقطع سقوط بحثي يجب أن يتضمن ثواني قبل الحدث وبعده؛ لذلك أصبح الحد الأدنى لفئة `fall` ثماني ثوانٍ.

## فصل البيانات ومنع التسريب
- جميع النوافذ المتداخلة من التسجيل نفسه تبقى داخل split واحد.
- التقسيم الافتراضي Recording-level: نحو 70/15/15 تدريب/تحقق/اختبار.
- لا تستخدم Test لاختيار عتبة السقوط أو درجة الحرارة؛ يتم ضبطهما على Validation فقط.
- لإثبات التعميم استخدم Leave-One-Room-Out وLeave-One-Person-Out، ثم اختبر جهازًا/راوترًا آخر إن أمكن.
- عند وجود أشخاص متعددين، لا تستخدم نوافذ الشخص نفسه في التدريب والاختبار عند ادعاء التعميم على أشخاص جدد.

## المقاييس الواجب نشرها
لا تكتفِ بـ Accuracy. انشر لكل فئة Precision وRecall وF1 وConfusion Matrix، إضافةً إلى:

- Fall recall: كم مثال سقوط التقطه النظام؟
- Fall precision: كم تنبيه سقوط كان صحيحًا؟
- False-positive windows: نوافذ غير سقوط صُنفت سقوطًا.
- False alarms per hour: احسبها من تسجيلات سلبية مستمرة مستقلة وموسومة يدويًا، وليس من عدد النوافذ وحده.
- زمن الاستجابة من بداية الحدث إلى التنبيه، واستهلاك الذاكرة وزمن الاستدلال.

## المقارنات العلمية
1. Baseline بسيط قائم على إحصاءات الإشارة.
2. CNN-BiLSTM القديم.
3. Athena 2.0 temporal residual model.
4. Ablation بدون temporal context، وبدون class balancing، وبدون calibration.
5. Raw vs normalized CSI، مع تفسير أثر كل اختيار.

## التشغيل

```bash
cd athena
python -m athena.crossval --group room --baseline-only
python -m athena.crossval --group room
python -m athena.crossval --group person
python -m athena.crossval --group room --ablate
```

## حدود وسلامة
عدد الغرف والأشخاص والأجهزة في التجربة الأولية يحد من قوة الاستنتاج. بيانات `fake_esp.py` صناعية لاختبار البرمجيات فقط؛ لا تستخدمها لتدريب نموذج فعلي أو ادعاء دقة سقوط. Athena نموذج بحثي وليس جهازًا طبيًا أو نظام إنقاذ، ولا يجوز الاعتماد عليه لحماية حياة أي شخص.
